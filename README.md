# SkillHub

可复用的 Agent Skills 集合。每个技能位于独立目录，使用标准 `SKILL.md` 元数据和按需加载的参考资料。

| 技能 | 说明 |
| --- | --- |
| [req-design-doc](req-design-doc/) | 从需求澄清、已有项目分析到可验收的技术设计文档；编码执行需明确授权 |
| [resume-optimizer](resume-optimizer/) | 简历快速/标准/深度优化、岗位匹配、事实核查及按需导出 |

## 使用说明
将目标技能目录安装到支持 Agent Skills 的客户端技能目录，具体位置按客户端文档配置。运行时由客户端根据 `name` 和 `description` 发现技能，按需读取 `SKILL.md` 与 `references/`、`scripts/`。

## 设计原则
- 只在关键风险或事实不明确时要求确认，减少冗长交互。
- 不编造数据、仓库事实、工具执行结果。
- 未经明确授权不自动启动编码、覆盖文件或推送部署。
- 保持平台中立；具体工具不可用时提供降级交付。
- 技能内容是操作规范，不等于已通过实际 Agent 端到端测试。

## 维护与验证
修改技能后至少检查 YAML frontmatter、相对路径和触发描述；建议使用兼容的 Agent Skills 校验工具，并以真实案例测试快速、异常和完整流程。
